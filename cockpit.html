Cockpit Preview

The desktop app for Build, for people who prefer a window to a terminal.

Cockpit is not a fourth product. It runs the steps of Build on your machine. The Gate and Readiness stay as they are.

Ask for access

This is a preview. You cannot download it yet.

What works today

  • Setup. A setup panel checks the framework, jq and the GitHub CLI on your machine. It installs what is missing.
  • Governed runs. Cockpit starts a coding agent job on your machine. The job stops at each gate and continues when you decide. A Claude job and a sandboxed Codex job both work.
  • Run view. Each run shows as a list of events, so you can see what the agent did.
  • Needs you. One panel lists what waits for you. A board shows each run.
  • Planning. A planning view shows your ORBIT plans and slices.
  • One project picker. Every screen uses the project that you pick.

Known limits

  • Sign-in with your ApexYard account is off. Cockpit works on your machine without an account. Sign-in with GitHub through ApexYard is not on yet. Planned
  • A run uses your own GitHub login. A governed run can call gh with your login, and that login can merge pull requests. Do not assume that a run cannot reach your GitHub credentials. We track a fix.

How to get it

There is no download yet. Today you build Cockpit from its source code. You need access to the source repository first. Write to us to ask for access.

Cockpit is not part of a plan yet. Until it has a download, the plans do not charge for it. We will say here when you can download it.
