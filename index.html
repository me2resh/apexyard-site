Install the framework

Every rule, hook and review agent is a plain file that you can read, change or remove.

Fork me2resh/apexyard into your organisation on GitHub. Then run these commands.

brew install jq
git clone https://github.com/your-org/apexyard.git
cd apexyard
bash bin/apexyard doctor

Fork me2resh/apexyard into your organisation on GitHub. Then run these commands.

sudo apt-get install jq
git clone https://github.com/your-org/apexyard.git
cd apexyard
bash bin/apexyard doctor

On Fedora, use sudo dnf install jq.

Fork me2resh/apexyard into your organisation on GitHub. Then run these commands.

The hooks are Bash scripts. Use Git Bash (from Git for Windows) or WSL. PowerShell and cmd.exe cannot run them.

winget install jqlang.jq
git clone https://github.com/your-org/apexyard.git
cd apexyard
bash bin/apexyard doctor

Run these commands in Git Bash. In WSL, use the Linux commands. Read the install guide.

Then open Claude Code in the folder and run /setup. Read the install guide for Codex, Cursor and OpenCode.
