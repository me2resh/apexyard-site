Install Build

Open source. MIT. Always free.

The hosted parts are paid. Every rule, hook and review agent is a plain file you can read, change or remove.

Install the command line tool with Homebrew. Then create your ops repository.

brew install me2resh/tap/apexyard
apexyard init --org <your-org> --name ops --private

This installs the command line tool if it is not there, then creates your ops repository.

npx create-apexyard --org <your-org> --name ops --private

You need git. apexyard doctor checks for jq and the GitHub CLI (gh) and tells you how to install what is missing.

Then open the new folder in your coding agent and run /setup. Works with Claude Code, Codex, Cursor, OpenCode, Pi and omp. On Windows, use Git Bash or WSL. Read the install guide.
