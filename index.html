Install Build

Open source. MIT. Always free.

The hosted parts are paid. Every rule, hook and review agent is a plain file you can read, change or remove.

Install the command line tool with Homebrew. Then create your <new-private-repo> repository.

brew install me2resh/tap/apexyard
apexyard init --org <your-org> --name <new-private-repo> --private

This installs the command line tool if it is not there, then creates your <new-private-repo> repository.

npx create-apexyard --org <your-org> --name <new-private-repo> --private
