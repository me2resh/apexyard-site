Previews

How the features that are not live yet might look.

Each card is a designed preview with sample data. The final design can change. This page is for review on staging only.

Previews

The hosted Gate dashboard

See each open pull request, what it is missing, and who it waits for.

Keel, shared across your organisation

See each rule, its owner, its version and whether it blocks a merge. Your agents read the same rules over MCP.

Evidence export

Export the record of each merge: the checks, the review, the named approver and the commit.

The team cockpit

Give people who never open a terminal the same steps: spec, plan, code and review, for each seat in the team.

The organisation view

See which pull requests skipped a step, across every repository. Trends by team show where steps get skipped.

The readiness score and trend

See a score for each repository and how it moves over time.

Readiness in your own CI

Run the audit in your CI with your own model key. Only the scores and findings go to the dashboard.

Readiness on a schedule

Audit every repository every week, and see the trend.

Review attested by your CI

Your CI can attest that each review ran, at the exact commit.

Agent sign-in over MCP

Connect a coding agent to the hosted Gate with your own sign-in.
