What the Gate does

Review

Rex

Rex reviews each pull request. The agent that wrote the change never reviews it.

Feedback where your team already reviews

Approval

The Founder

A person your team names approves each merge. An agent never gives that approval.

An agent never approves its own work

The agent that wrote a change does not review it. A separate review agent with its own persona reviews it, and it can run on a different model. By default, reviewers run on a stronger model than builders. A person your team names approves the merge. An agent never gives the final sign-off.

What the GitHub App can see

The App does not fetch the files in your repository, and it has no Contents permission. From each pull request it takes the title, the description and the names of the changed files, never the code.

  • Pull requests: read. Titles, descriptions, reviews and the list of changed files.
  • Checks: write. To post the ApexYard check on each pull request.
  • Metadata: read. Repository names, and who can write to each repository.

The check blocks a merge only when you make it required in GitHub. You can remove the App at any time.
